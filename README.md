# Blinkit Sales Dashboard (Power BI)

## Project Overview
This project analyzes Blinkit's grocery sales data using Power BI. The dashboard provides insights into sales performance, customer ratings, outlet performance, and product categories to support business decision-making.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Key KPIs
- Total Sales
- Average Sales
- Average Rating
- Number of Items Sold

## Dashboard Features
- Sales by Outlet Location
- Sales by Outlet Size
- Sales by Item Type
- Sales by Fat Content
- Outlet Establishment Trend
- Interactive Filters (Slicers)

## Skills Demonstrated
- Data Cleaning using Power Query
- Data Modeling
- DAX Measures
- Interactive Dashboard Design
- Business Insights and Reporting
